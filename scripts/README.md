# Сценарии и раскадровки

Одна папка на тему: `scripts/<тема>/<slug>.md` (сценарий по `templates/script.template.md`)
и `scripts/<тема>/<slug>.storyboard.md` (раскадровка по планам 4 с по `templates/storyboard.template.md`).
Примеры тем: `dead-sea-scrolls/`, `gobekli-tepe/`, `library-of-alexandria/`.
