# Science History

Научно-популярный YouTube-канал о научной истории: раскопки и находки, древние рукописи и книги,
история цивилизаций и религий. Ролики собираются кодом на Remotion: реальные артефакты из музеев,
карты, хронологии, кинетическая типографика, реконструкции с пометками.
