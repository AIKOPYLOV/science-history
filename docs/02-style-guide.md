# 02. Визуальный стиль канала

Ощущение: **музейная документалистика** — тёплый свет на артефакте, пергамент, камень и золото, глубокие тени.
Артефакт — герой кадра; графика деликатная: подписи как музейные этикетки, хронологии, карты, выделение деталей.

## Формат кадра
- 1920×1080, 30 fps. Безопасные поля: **120 px** слева/справа, **90–110 px** сверху/снизу.
- Артефакт/рукопись — главный объект; текст не перекрывает надписи и лица на предмете.
- Shorts (по запросу): 1080×1920, поля 80 px, текст крупнее на 20%.

## Палитра (`video/src/theme.ts → colors`)
| Токен | Цвет | Для чего |
|---|---|---|
| `bg` | `#0e0b08` | фон (тёмная «музейная» комната) |
| `text` | `#f2eadb` | основной текст (цвет пергамента) |
| `muted` | `rgba(242,234,219,.64)` | подписи, пояснения |
| `accent` | `#d6a84e` | золото: акцент, ключевая дата/слово |
| `hot` | `#b5482e` | киноварь/охра: важное, утрата, конфликт |
| `cool` | `#7d9aa6` | лазурит/вода: нейтральное сравнение |
| `green` | `#8b9a5b` | бронзовая патина: территории на карте |
| `neutral` | `#a39a8b` | камень |
| `line` | `rgba(242,234,219,.18)` | линии, шкалы времени |

Акцентный градиент для дат и цифр: `#f6e1ad → accent → hot` (сверху вниз).

## Шрифты (локально в `video/public/fonts`, OFL)
- **Unbounded** — заголовки и крупные даты (300 / 500 / 700). **Manrope** — подписи (400 / 600 / 800).
- Музейная «этикетка» под артефактом: название · датировка · место находки · музей (Manrope 22–26).
- Цитаты из источников — курсивом, с атрибуцией (автор, сочинение, перевод).
- Даты: «около 1250 г. до н. э.», «III в. н. э.»; века римскими цифрами.

## Движение
- Кривая по умолчанию — `easeOutExpo`; `spring({damping: 200})` для объектов.
- Неподвижные изображения **всегда в движении**: медленный наезд 1.02 → 1.15, панорама вдоль строки текста,
  параллакс (вырезанный предмет поверх фона), «луч света»/маска, выделяющая деталь (печать, надпись, рисунок).
- Текст: слова появляются снизу из размытия (`RevealText`); годы докручиваются (`Counter`).
- Склейки: плавный наплыв 0,4 с; световая вспышка — только на смене эпохи/главы.
- Правила качества движения (склейка на движении, появление из крупного, без «мёртвых» кадров) —
  те же, что в Kosmos/Wildlife (см. `docs/references/motionmaxxing/` и skill `motion-design`).

## Постобработка
- Плёночное зерно (`Grain`, 0.08–0.12), виньетка — «музейный» свет.
- Футаж/фото: `contrast(1.08) saturate(0.9)`, затемнение 0.15–0.5 под текст, градиент снизу под подпись.

## Типовая инфографика для научной истории
- **Шкала времени** — горизонтальная линия, события-метки, «камера» едет вдоль эпох; масштаб соблюдён.
- **Карта** — древний мир: контуры (Natural Earth), города/находки точками, маршруты, границы империй
  по датам (данные Pleiades и научных атласов; skill `remotion-maps`).
- **Артефакт крупно** — выделение детали маской + выноска с переводом надписи.
- **Сравнение масштаба** — предмет рядом с ладонью/человеком/монетой.
- **Стратиграфия раскопа** — слои земли с датировками.
- **Родословная текста** — как рукопись копировалась: оригинал → копии → переводы.

## Звук
- Спокойная музыка без ударных (струнные, хор, дроны), шорохи бумаги, ветер пустыни. Музыка ниже голоса ≥ 12 дБ.
- «Удар» — на ключевой дате/цифре; «вжух» — только на смене эпохи. Итог −14 LUFS (делает `render.sh`).

## Чего не делаем
- «Мистический» стиль: туман, молнии, кровавые шрифты, «тайны, которые скрывают учёные».
- Неоновые и фиолетовые «ИИ-градиенты», рамки, эмодзи в кадре.
- Текст поверх надписей артефакта; ИИ-картинки без пометки; карикатуры на религиозные сюжеты.
