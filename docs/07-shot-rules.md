# 07. Правила монтажа: смена кадра, разнообразие, источники

Требования пользователя (обязательные для каждого ролика):

1. **Кадр меняется не реже чем раз в 4 секунды.** 60 с ролика = минимум **15 планов**.
2. **Любые два плана похожи не более чем на 90 %** (SSIM ≤ 0.90) — и соседние, и разнесённые по времени.
   Нельзя повторять один и тот же фон с другим текстом.
3. **Везде моушн-графика и инфографика.** Нет «голых» кадров: на каждом плане есть движение камеры
   и хотя бы один графический слой (подпись, счётчик, схема, стрелка, маркер, плашка).
4. **Смешанные источники:** стоки и футаж агентств + картинки с лицензией CC (Openverse/Wikimedia/Google-фильтр)
   + музеи/библиотеки/архивы открытого доступа + собственная генерация (карты, хронологии, схемы, ИИ-иллюстрации).

Проверка автоматическая — `video/scripts/qc_shots.py` (запускается в конце `scripts/render.sh`).
**Ролик, не прошедший QC, не сдаётся.**

## Как считается
- Видео анализируется 4 раза в секунду, кадры уменьшаются до 192×108 в оттенках серого (зерно не влияет).
- **Темп:** для каждого момента t сравнивается кадр t и кадр t + 4 с. SSIM ≥ 0.90 → нарушение
  (картинка за 4 секунды почти не изменилась).
- **Длина плана:** план > 4.0 с (+0.5 с — погрешность поиска склейки при наплыве и шаге анализа 0.25 с) → нарушение. Склейка ищется по кадрам через 1 с (SSIM < 0.6).
- **Уникальность:** средний кадр каждого плана сравнивается со всеми остальными. SSIM > 0.90 → нарушение.
- Первые/последние 0.75 с и почти чёрные кадры (затемнения) не проверяются.

```bash
python3 video/scripts/qc_shots.py video/out/<slug>.mp4   # отчёт: video/out/<slug>.qc.json
```

## Как строить ролик, чтобы пройти QC
- **Планируй по планам, а не по сценам.** В раскадровке — строка на каждый план 3–4 с
  (шаблон `templates/storyboard.template.md`).
- Сцена из нескольких фактов = несколько планов: каждая цифра на **своём** фоне/ракурсе
  (другой клип, другой участок футажа, другой артефакт/место, крупный план ↔ общий план).
- Один длинный клип можно использовать несколько раз, только если участки визуально разные
  (проверяется QC) — например, разные секунды пролёта камеры.
- Варианты смены плана без новой картинки: смена масштаба ×1.5+ и точки фокуса, переход камеры
  к другому объекту, смена схемы (график → карта → сравнение).
- Текстовые плашки поверх одного фона **не считаются** новым планом.
- Две «тёмные» инфографики подряд (схема на чёрном → график на чёрном) QC видит как один план.
  Давай каждой инфографике свой фон (футаж/фото с затемнением) или ставь между ними реальный кадр.
- Переходы: light leak / наплыв 0.5–1 с; резких «тиктоковых» склеек не делаем — динамика за счёт частой,
  но плавной смены кадра.

## Как это сделано в коде
- В конфиге ролика: `cut: 'crossfade'`, `crossfadeFrames: 12`, каждый план `durationInFrames: 132`
  (120 кадров = 4 с + 12 на наплыв), последний — 120. Тогда 15 планов = ровно 1800 кадров (60 с).
- `leakAt: [индексы]` — вспышка + «вжух» только на смене глав (2–3 раза за минуту), а не на каждой склейке.
- Тип `stat` — одна цифра на план; `custom` — своя сцена (карта, шкала времени, схема) прямо в конфиге.
- Эталон монтажа: `video/src/videos/venus-stock/` в репозитории Kosmos (15 планов, QC пройден).

## Типовая сетка 60 с (15 планов по 4 с)

| # | План | Источник |
|---|---|---|
| 1 | Открытие: место действия (руины, пустыня, храм), общий план | сток-видео |
| 2 | Заголовок на другом фоне | футаж (другой участок) |
| 3 | Шкала времени: где мы в истории | своя графика |
| 4 | Артефакт крупно + музейная «этикетка» | музей CC0 + наезд/маска |
| 5–7 | По одной ключевой цифре на план | 3 разных фона |
| 8 | Схема/график | своя инфографика |
| 9 | Сравнение полосами | своя инфографика |
| 10 | Архивное фото раскопок / рукопись | LoC / Wikimedia / NARA (PD) |
| 11–12 | Гипотеза / реконструкция | анимация агентства / ИИ-иллюстрация с пометкой |
| 13 | Карта: где найдено / маршрут / империя | своя графика (Natural Earth, Pleiades) |
| 14 | Крючок | сток-видео |
| 15 | Финальный титул | футаж + титул |
