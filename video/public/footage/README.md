# public/footage

Сюда кладутся скачанные стоковые клипы и картинки (Pexels, Pixabay, Wikimedia, Internet Archive, NARA и т. д.); изображения артефактов — в `public/images/`.

- Имя файла: `<источник>-<что-в-кадре>.mp4`, например `pexels-desert-ruins-dawn.mp4`, `nara-excavation-1930.mp4`.
- Каждый файл обязательно записывается в `footage.manifest.json` ролика (источник, ссылка, лицензия, подпись).
- Большие исходники (>50 МБ) в git не коммитим — держим ссылку в манифесте, а скачивание повторяем скриптом.
